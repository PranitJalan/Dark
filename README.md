
# Mr.Doctor
## Project Info
The project is made in Godot using GDScript.   
It was made over 10 hours by adding various scenes and nodes. The main UI is controlled by the control scene and the main gameplay by the level scene.
Currently no executable is available, to play it you must go to
 Itch.io-[Mr. Doctor](https://salprokite.itch.io/mr-doctor)                  

 ### Setup
 To open the project and edit it you must - 
 - Download repoistory as a zip
 - Extract it in a folder
 -  Go to Godot and click import and navigate to project.godot in the folder where you extracted the zip
- Voila! The project is now running in your engine edit it all you want

## Game
You are suddenly half blind, get to Mr.Doctor and get cured.

### Game
. The instructions are -
- Use A for left, D for right and W for Jump
- Collect runes and cures.
- Choose carefully, they matter.
- Get to Mr.Doctor
- Explore all endings
